# Drone Control

WPF-пульт (.NET 10, MaterialDesign 3) для TX-дронов из приложения KY FPV.
Протокол восстановлен из `DeviceTXFragment` / `FlyController` декомпилированного APK.

Полная документация: [docs/DOCUMENTATION.md](docs/DOCUMENTATION.md).

## Запуск

Нужен .NET 10 SDK.

```
dotnet test
dotnet run --project src/DroneControl.Wpf
```

1. Подключите ПК к Wi-Fi дрона (дрон — `192.168.1.1`).
2. «Подключить» → начинается heartbeat `01 01` раз в секунду.
3. Включите «Передача управления» → пакеты управления каждые 50 мс.
4. Газ — вертикальный слайдер слева, остальное — кнопки-пресеты.
5. **STOP** (или Esc) прерывает текущую команду и ставит стики в центр.
   «Стоп моторов» — аварийное отключение моторов (флаг `0x04`), дрон упадёт.

Режим **Dry-run** формирует и показывает пакеты, но ничего не отправляет.

## Протокол (UDP 192.168.1.1:7099)

| Пакет | Байты | Период |
|---|---|---|
| Heartbeat | `01 01` | 1 с |
| Управление | `03 66 RR PP TT YY FF CS 99` | 50 мс |
| Выход из управления | `08 01` | однократно |

`RR` крен, `PP` тангаж, `YY` рыскание: 1…255, центр 128. `TT` газ 0…255.
`CS = RR ^ PP ^ TT ^ YY ^ FF`.

| Флаг | Значение | Как держит оригинал |
|---|---|---|
| `0x01` | Взлёт | 1 с |
| `0x02` | Посадка | 1 с |
| `0x04` | Аварийный стоп моторов | 1 с |
| `0x08` | Флип | 600 мс |
| `0x10` / `0x20` / `0x40` | Не подтверждены (headless / возврат / свет?) | — |
| `0x80` | Калибровка гироскопа | 2 с |

Порядок крен/тангаж в байтах 1–2 и знак направлений взяты из декомпиляции, но на живом
дроне не проверены. Первые тесты проводите без пропеллеров.
